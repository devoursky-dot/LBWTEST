CH 01

AI 디자인 스킬 (AI Design Intelligence & Anti-Slop)

Anthropic, UI UX Pro Max v2.0, Hallmark, Taste Skill, Impeccable의 철학을 융합하여 기계적인 클리셰를 차단하고 4대 상태를 완전하게 구축합니다.

UI UX Pro Max: 4대 필수 상태 시뮬레이터 192 Rules

버튼을 클릭하여 화면이 가질 수 있는 4대 필수 상태(로딩, 비어있음, 오류, 성공)를 직접 확인하세요.

Hallmark: 3단계 품질 게이트 (Together AI) Quality Gates

AI가 생성한 결과물을 배포하기 전 통과시키는 3단계 엄격한 검증 시스템입니다.

Gate 1: The Floor (절대 배포 불가)

명도 대비 4.5:1 미달, 모바일 가로스크롤 깨짐, 가짜 더미 데이터는 빌드 즉시 실패 처리.

Gate 2: Reflex Gates (AI 습관 차단)

제목 위 불필요한 미니 태그 남발, 한 단어만 다른 색 칠하기, 껍데기 전송 폼 원천 배제.

Gate 3: Finish Checks (장인정신 마감)

1px 내부 하이라이트, 가독 라인 70ch 제한, 제품 도메인에 뿌리내린 어휘 사용.

Impeccable: 24개 협업 명령어 어휘 체계 pbakaus/impeccable

에이전트에게 모호한 프롬프트 대신 정밀한 디자인 명령어를 내려 점진적으로 완성도를 높입니다.

/impeccable audit

접근성, 명도비, 반응형 전수 검사

/impeccable critique

UX 위계와 사용자 감성 분석

/impeccable polish

1px 정렬 및 시각적 최종 마감

/impeccable distill

중첩 카드와 과도한 장식 제거

CH 03

웹 인터랙션 & 물리학 (Web Interactions & Physics)

Emil Kowalski(Linear, Vercel)의 스프링 물리학, React Bits의 크리에이티브 컴포넌트, Keyframe Gallery의 60fps GPU 렌더링 규약을 실증합니다.

Emil Kowalski 스프링 물리학 vs 기계적 Linear Linear & Vercel Craft

두 버튼을 각각 마우스로 꾹 눌러보세요. 손가락에 감기는 탄성 피드백의 극명한 차이를 체감할 수 있습니다.

1. 나쁜 예: 기계적 linear 애니메이션 (로봇 같고 둔탁함)
2. 좋은 예: Emil Kowalski 탄성 피드백 (scale 0.97 + cubic-bezier)
Keyframe Gallery: GPU 가속 60fps 원칙 keyframe.gallery

레이아웃 리플로우(Reflow)를 일으키는 속성과 GPU 컴포지터(Compositor)만 사용하는 속성의 차이입니다.

❌ 절대 애니메이션 금지 (CPU 버벅거림 유발) width, height, top, left, margin, padding
✅ 60fps 보장 GPU 컴포지트 속성 transform (translate3d, scale, rotate), opacity
